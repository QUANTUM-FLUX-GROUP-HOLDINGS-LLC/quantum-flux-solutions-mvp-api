# Handoff Logs

This folder contains session-by-session logs of development. 
Whenever you start a new session (especially with an AI assistant), read the latest numbered file here to understand the current state of the project.

**How to add a new handoff:**
Create a new file named `00X-feature-name.md` (e.g., `002-file-uploads.md`) and document:
1. What was done in that session.
2. What broke or what caveats exist.
3. What the next developer/AI should do next.
