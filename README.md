# Quantum Flux Solutions - Fintech MVP

Monorepo for Credit Repair, Taxes, and Bookkeeping services (U.S. Only).

## Tech Stack
- **Backend:** NestJS (TypeScript)
- **Frontend:** Next.js (React)
- **Database:** PostgreSQL
- **Third-party APIs:** Stripe, Plaid, QuickBooks

## Governance Rules
1. All code (folders, variables, functions) MUST be in English.
2. No accents or special characters in code.
3. Commits must follow Conventional Commits format.
4. Run `./scripts/check-english.sh` before committing.
